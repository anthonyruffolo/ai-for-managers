# Student GitHub Help

This course uses basic GitHub collaboration as part of learning how to build with AI. Advanced programming is not expected.

## What students need to do

Students should be able to:

1. Create or access a GitHub account.
2. Create or access the repository used for the student dashboard.
3. Understand where their files live.
4. Make a small change with AI assistance.
5. Review the change before accepting it.
6. Commit the change with a useful message.
7. Push the change to GitHub.
8. Confirm the dashboard still works.

## The AI-assisted building loop

Use this cycle when you do not know how to complete a task:

**Explain the goal → provide context → ask AI questions → develop an approach → build → test → identify problems → iterate.**

The goal is not to memorize code. The goal is to know how to use AI to figure out an unfamiliar task and then verify the result.

## Basic vocabulary

**Repository:** your project's files and history.

**Branch:** a separate line of work that lets you make changes without immediately changing the stable version.

**Commit:** a saved checkpoint describing a change.

**Push:** send your committed changes to GitHub.

**Pull:** bring newer changes from GitHub into your local copy.

**Pull request:** ask for a branch to be reviewed and merged.

**Merge:** combine approved work into the target branch.

## Before you submit a build

- [ ] The requested feature is present.
- [ ] The feature works when I use it.
- [ ] I checked important AI-generated claims.
- [ ] I did not include private or confidential information.
- [ ] I can explain what I built and why.
- [ ] I can identify what AI helped with and what I decided myself.
- [ ] I tested the dashboard after making the change.

## If AI-generated code does not work

Do not blindly accept another generated answer. Give the AI the exact error, explain what you expected to happen, ask it to diagnose the likely cause, make one change at a time, and test again.

## Never put these in GitHub

- Passwords
- API keys or tokens
- Private student information
- Confidential business information you do not have permission to share
- Credentials or secrets
