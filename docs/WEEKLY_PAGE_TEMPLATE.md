## Implementation notes

- Keep the weekly navigation and visual structure consistent.
- Do not silently rewrite approved instructional content during implementation.
- If a builder's material conflicts with an earlier/later week, flag it for team review.
- Test the completed page from a student perspective before marking it ready.
