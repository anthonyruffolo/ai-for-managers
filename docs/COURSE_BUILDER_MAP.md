## Implementation boundary

Builders own the instructional package. Anthony owns the technical implementation and class-dashboard presentation after approval.

### Builder owns

- Lesson/content
- Key terms
- Student build definition
- Student directions
- Example/model
- Submission requirements
- Rubric/answer key
- Quiz/test/discussion material when assigned
- Dashboard requirements needed to support the week

### Anthony owns

- Course navigation and page structure
- Weekly page implementation
- Assignment/submission containers
- Quiz/test/discussion containers
- Progress indicators
- Dashboard build tracker
- GitHub workflow and repository organization
- Adding approved examples/resources/directions/rubrics
- Student-view testing and technical fixes

## Coordination rule

Builders should review the weeks before and after their assignment before finalizing content. The goal is a connected Week 1 → Week 15 experience rather than isolated sections.
