## Questions

1. What is an AI assistant?
   - a. A tool that only stores files
   - b. A tool that can help generate, summarize, analyze, or organize information
   - c. A software update
   - d. A company database

2. Which is the best example of a business use for an AI assistant?
   - a. Making an unreviewed final hiring decision
   - b. Drafting a meeting agenda or summarizing notes for manager review
   - c. Sharing employee medical records in a public chatbot
   - d. Replacing all manager communication

3. What is a plugin?
   - a. A type of confidential information
   - b. An add-on that gives an AI tool access to additional features or services
   - c. A password manager
   - d. A spreadsheet formula

4. What is an integration?
   - a. Connecting two tools or systems so they can exchange information or work together
   - b. Removing a tool from a dashboard
   - c. Writing a stronger prompt
   - d. Creating a new employee policy

5. What does API stand for?
   - a. Automated Program Instruction
   - b. Application Programming Interface
   - c. Artificial Platform Integration
   - d. Advanced Privacy Information

6. What is the main purpose of an API?
   - a. To allow different software applications to communicate with one another
   - b. To prevent systems from sharing data
   - c. To replace all management decisions
   - d. To create a dashboard homepage

7. Which factor is most important when choosing an AI tool for a management task?
   - a. The tool’s logo and popularity
   - b. Whether it fits the task, meets privacy requirements, and produces useful output
   - c. Whether it produces the longest answer
   - d. Whether it is the newest tool available

8. Which item should be included when comparing AI tools?
   - a. Purpose, strength, limitation, risk, and management use case
   - b. The employee’s personal password
   - c. Only the tool’s price
   - d. Only the tool’s name and logo

9. Which is an example of a limitation of an AI tool?
   - a. It can quickly produce a first draft
   - b. It may provide inaccurate, incomplete, or biased information
   - c. It can organize ideas
   - d. It can save time on routine tasks

10. Why should managers verify AI-generated information before using it?
    - a. AI responses may be inaccurate or lack important context
    - b. AI tools cannot create written content
    - c. Verification makes a tool more expensive
    - d. Managers are not allowed to use AI

11. Which information should not be entered into a public AI tool unless it is specifically approved?
    - a. A general public news article
    - b. A generic brainstorming prompt
    - c. Employee Social Security numbers, client data, or confidential company information
    - d. A public job posting

12. What is the purpose of the AI Tools page in the dashboard project?
    - a. To compare AI tools and identify when they can be used responsibly
    - b. To store employee passwords
    - c. To make automated business decisions
    - d. To replace the dashboard homepage

13. What should students define before building their AI Management Dashboard?
    - a. A dashboard name, purpose, target user, and management problem
    - b. A personal social media account
    - c. A final company AI policy
    - d. A list of employee salaries

14. Which section would be most appropriate for storing examples of effective prompts?
    - a. Workforce
    - b. Verification
    - c. Prompt Library
    - d. Implementation

15. Which statement best describes responsible AI use in management?
    - a. AI should make all final decisions independently.
    - b. Managers should use AI to support their work while maintaining human judgment, privacy, and accountability.
    - c. Any information can be entered into public AI tools.
    - d. AI output does not need to be reviewed.
